NSS APP - Database Restructure Plan
====================================

### NamingConventions
- Use camelCase everywhere. Normalize and correct spellings.

### UsersCollectionSchema (final)
- name: string
- rollNumber: string
- instituteOutlookId: string   // canonical Auth email
- uid: string                  // Firebase Auth UID
- unreadCount: number
- userType: 'admin' | 'student'
- wings: string[]              // zero or more wings
- password: string             // DO NOT store plaintext; rely on Firebase Auth

### SourceOfTruth
- Login email: users/{rollNumber}.instituteOutlookId
- Role: users/{rollNumber}.userType ('admin'|'student')

### AuthConsolidation (use only users)
- Stop using NSS_ADMINS/Student for login email.
- Sign in: signInWithEmailAndPassword(instituteOutlookId, password).
- Forgot password: send to users.instituteOutlookId.
- Role checks: userType == 'admin' for admin-only features.
- Do not use year anywhere.

### SecurityRules (firestore.rules)
- isAdmin(): exists(users/{request.auth.uid}) && get(users/{request.auth.uid}).data.userType == 'admin'

### MigrationSteps
- users.userType: Admin1/Admin2/Admin → 'admin'; others → 'student'.
- users.instituteOutlookId: backfill from NSS_ADMINS.College_Email or Student.Gmail_ID when missing.
- Remove users.year from all docs.

### CodeTouchpoints (update to new flow)
- LoginFormActivity.kt / LoginActivity.kt
  - Read users/{rollNumber}.instituteOutlookId for email.
  - Auth with that email; store userType ('admin'|'student') in SessionManager.
  - Remove year from session.
  - Forgot password uses instituteOutlookId.
- Role checks
  - AttendanceManagerFragment.kt, QRAttendanceViewModel.kt, CalendarFragment.kt, AdminAccessControl.kt: replace Admin1/Admin2 checks with userType == 'admin'.
- SessionManager.kt
  - Store only 'admin' or 'student'. Remove Admin1/Admin2 constants and any year-based logic.

### VerificationChecklist
- Login works for admin and student via users.instituteOutlookId only.
- Forgot password email sends correctly.
- Admin-only screens gated by userType == 'admin'.
- Rules allow admin actions; block student actions.
- No references to NSS_ADMINS/Student/year remain.
